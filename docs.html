Getting Started

Secure Tunnel (TunnelJS) is a transparent application-layer API gateway built for Express and Node.js. It acts as an encryption-first pipeline between clients and backend routers, abstracting endpoints under a single POST /api/gateway layer.

> [!IMPORTANT] > Secure Tunnel is not a replacement for HTTPS. It complements transport-layer security with client-server signing, request verification, application payloads compression, and replay attacks prevention.

Installation

Install the Secure Tunnel components into your Node.js backend and client projects:

Shell 
# Install Express Server Package
npm install @secure-tunnel/core @secure-tunnel/express @secure-tunnel/plugins @secure-tunnel/crypto @secure-tunnel/compression @secure-tunnel/logger

# Install Frontend Client SDK
npm install @secure-tunnel/core @secure-tunnel/client @secure-tunnel/plugins @secure-tunnel/crypto @secure-tunnel/compression

Express Server Setup

Integrate the Secure Tunnel Gateway middleware at the top of your Express application to automatically decrypt, check signatures, log, and forward incoming requests internally.

Integration Code Example

server.ts 
import express from 'express';
import { createTunnelGateway } from '@secure-tunnel/express';

const app = express();

// The gateway intercepts incoming JSON TunnelEnvelopes
app.use(express.json());

// Symmetric Keys (Must match clients exactly)
const secretKey = 'my-super-secret-key-32-chars-long-123456';
const signatureKey = 'my-signing-hmac-key-32-chars-long-123456';

// Register the Gateway Middleware
app.use(
  createTunnelGateway({
    endpoint: '/api/gateway',
    secretKey,
    signatureKey,
    encryption: true,
    signing: true,
    compression: true,
    replayProtection: true, // Requires Redis/InMemory caching
  })
);

// Declare standard internal API endpoints normally!
// Incoming requests to /api/gateway are transparently routed to these routes.
app.get('/api/products', (req, res) => {
  res.json({ products: [{ id: 1, name: 'Secure Device' }] });
});

app.post('/api/login', (req, res) => {
  res.json({ token: 'jwt-token-xyz' });
});

app.listen(3000, () => console.log('Secure Gateway running on port 3000'));

Client SDK Setup

Configure the SDK client to transparently map outgoing API calls to the gateway endpoint, processing payloads symmetrically.

Transparent Request Invocation

client.ts 
import { createTunnel } from '@secure-tunnel/client';

const client = createTunnel({
  endpoint: 'http://localhost:3000/api/gateway',
  secretKey: 'my-super-secret-key-32-chars-long-123456',
  signatureKey: 'my-signing-hmac-key-32-chars-long-123456',
  encryption: true,
  signing: true,
  compression: true,
});

async function runDemo() {
  // Invokes client.request('POST', '/api/login', { ... }) behind the scenes,
  // packing it into a secure, encrypted Gzip TunnelEnvelope, hits /api/gateway,
  // and transparently decrypts the response token.
  const response = await client.post<{ token: string }>('/api/login', {
    username: 'admin',
    password: 'password123',
  });

  console.log('Decrypted API payload token:', response.token);
}

runDemo();

React & Axios Adaptations

Apply the transparent tunnel to standard third-party libraries like Axios, or inject client states using React Context.

Axios Interceptor Integration

Intercept all outbound requests and response envelopes dynamically using standard interceptor bindings:

axios-setup.ts 
import axios from 'axios';
import { createTunnel, applyAxiosInterceptor } from '@secure-tunnel/client';

const axiosInstance = axios.create({
  baseURL: 'http://localhost:3000',
});

const tunnelClient = createTunnel({
  endpoint: 'http://localhost:3000/api/gateway',
  secretKey: 'my-super-secret-key-32-chars-long-123456',
  signatureKey: 'my-signing-hmac-key-32-chars-long-123456',
  encryption: true,
  signing: true,
  compression: true,
});

// All calls via axiosInstance will now pass through the tunnel!
applyAxiosInterceptor(axiosInstance, tunnelClient);

async function testAxios() {
  // Over-the-wire request is actually POST to /api/gateway!
  const res = await axiosInstance.get('/api/products');
  console.log('Products decrypted automatically:', res.data);
}

React Hook context Provider

App.tsx 
import React from 'react';
import { TunnelProvider, useTunnel, createTunnel } from '@secure-tunnel/client';

const client = createTunnel({
  endpoint: 'http://localhost:3000/api/gateway',
  secretKey: 'my-super-secret-key-32-chars-long-123456',
  signatureKey: 'my-signing-hmac-key-32-chars-long-123456',
});

export default function App() {
  return (
    <TunnelProvider client={client}>
      <Dashboard />
    </TunnelProvider>
  );
}

function Dashboard() {
  const api = useTunnel();

  const fetchItems = async () => {
    const products = await api.get('/api/products');
    console.log(products);
  };

  return <button onClick={fetchItems}>Load Products</button>;
}

Writing Custom Plugins

Extend the client or gateway processing pipeline by writing custom classes that implement standard event lifecycle hook handlers.

Hooks Pipeline Stages

Plugins can intercept, inspect, and modify envelopes or decrypted payloads during stages of the pipeline:

custom-auth-plugin.ts 
import { TunnelPlugin, TunnelRequest, TunnelPluginContext } from '@secure-tunnel/core';

export class DeviceFingerprintPlugin implements TunnelPlugin {
  public readonly name = 'device-fingerprint';

  // Executed on the client side before packaging
  public async beforeEncrypt(envelope: any, context: TunnelPluginContext): Promise {
    // Append telemetry metadata payload header
    context.state.deviceId = 'macbook-pro-m3-id';
  }

  // Executed on the server gateway inside the decrypted tunnel state
  public async beforeForward(request: TunnelRequest, context: TunnelPluginContext): Promise {
    // Ensure the device id matches acceptable headers list
    const incomingId = request.headers['x-device-id'];
    if (!incomingId || incomingId !== 'macbook-pro-m3-id') {
      throw new Error('Device untrusted');
    }
  }
}
